Confirmation · Document Timing

見積・請求は
どの時点で作りますか

システムは今、事前相談 → 本見積 → 請求書 → 領収書という順番で書類を作る前提で動いています。
この資料は、その前提が実際の現場の進め方と合っているかをご確認いただくためのものです。
最後に、確認させていただきたい点を9つまとめています。番号でお知らせください。

Overview

まず、全体の流れ

書類は4種類です。左から順に作ります。前の書類の内容が次の書類に引き継がれるので、途中から始めたり、順番を飛ばしたりはできません。

事前相談見積 ご相談の段階でお出しするお見積り
→
本見積 内容が固まった段階の正式なお見積り
→
請求書 施行後、実際にご請求する金額
→
領収書 ご入金を確認したあとにお渡しするもの

矢印のところで、前の書類の品目・金額がそのまま次の書類に写されます。写したあとは、それぞれ別々に直せます。

Timeline

いつ、どの書類を作る想定か

ご葬儀の進行に合わせて並べると、こうなります。金色の丸が付いている時点で、書類を作る操作が入ります。

  1. ご相談（生前のご相談・お問い合わせ） まだ施行が決まっていない段階です。
    事前相談見積をつくる

    案件の一覧から「見積書作成」を押すと、必ずこの事前相談見積として作られます。プランを選び、棺やお骨壺などの品目を選んで金額を出します。

    番号は自動で振られます。まだ受付日が入っていなければ、作った日の年月がもとになります。

  2. ご逝去・ご依頼・お迎え 案件として受け付け、受付日時を登録する段階です。
  3. ご家族との打合せ 祭壇・棺・お料理などを実際に決めていく段階です。
    本見積をつくる

    見積の画面で「本見積を作成」を押すと、事前相談見積の内容がまるごと写された新しい見積ができ、そちらに切り替わります。以後の変更はこちらで行います。

    番号は自動では振られません。必要であれば手で入力します。空欄のままでも保存できます。

  4. 通夜 この時点では新しい書類は作りません。内容の変更は本見積を直します。
  5. 葬儀・告別式・火葬 同じく、変更は本見積を直します。
  6. ご精算 実際にかかった分を確定してご請求する段階です。
    請求書をつくる

    案件の一覧から「請求書作成」を押すと、本見積の内容が写された請求書ができます。当日増えた品目・減った品目は、ここで直します。

    番号は自動で振られます。受付日の年月がもとになります。

  7. ご入金 ご入金を確認した日を登録します。
    入金を登録し、領収書を出す

    「入金登録」で入金日とメモを記録します。登録すると領収書が出せるようになります。

    金額はご請求額の全額を一度にいただく前提です。分割や一部入金を記録する欄は今のところありません。

Rule

一度先に進むと、前の書類は直せません

これがいちばん大事な決まりです。書類を次に進めると、ひとつ前の書類には鍵がかかり、見るだけになります。金額の食い違いを防ぐためです。

🔒 本見積を作ると 事前相談見積は 閲覧のみ になります（直したいときは本見積の方を直します）
🔒 請求書を作ると 本見積は 閲覧のみ になります（直したいときは請求書の方を直します）

なお、前の書類がないと次には進めません。本見積がなければ請求書は作れず、請求書がなければ入金登録も領収書もできません。

Questions

確認させていただきたいこと

以下の9点について、実際の運用に合っているかお聞かせください。合っていなければ、その通りに直します。

作るタイミングについて

  1. 急なご依頼で事前のご相談がなかった場合も、最初の書類は「事前相談見積」として作ることになります。名称・進め方としてご不便はありませんか。

    Now最初に作る見積は必ず事前相談見積になります。いきなり本見積から作ることはできません。

  2. 事前相談見積から本見積に切り替えるのは、どの時点が適切でしょうか。打合せが終わった時点ですか、それとも施行が終わってからですか。

    Now切り替えた時点で事前相談見積は閲覧のみになります。切り替える時期の決まりはシステム側にはありません。

  3. 施行当日に品目が増えたり減ったりした場合、請求書の方だけを直す進め方でよろしいですか。

    Now請求書を作った時点で本見積は閲覧のみになるため、直せるのは請求書だけです。本見積は打合せ時点の記録として残ります。

  4. ご相談だけで終わり、施行にならなかった案件の見積は、そのまま残しておく扱いでよろしいですか。

    Now作った見積を消す機能はありません。事前相談見積のまま残ります。

番号と日付について

  1. 本見積には番号が自動で振られません。番号を付ける決まりはありますか。付けない運用でよろしいですか。

    Now事前相談見積と請求書は自動、本見積だけ手入力です。空欄のままでも保存できます。

  2. 書類番号の年月は「受付日」がもとになります。受付より前に作る事前相談見積は、ご相談した日の年月になりますが、それでよろしいですか。

    Now受付日が未入力の間は、書類を作った日の年月を使います。あとから受付日を入れても、すでに振られた番号は変わりません。

  3. 見積書・請求書に印字されるのは受付日だけです。「発行日」や「お見積り日」を別に出す必要はありませんか。

    Now書類を作った日・出した日は印字されません。

  4. 領収書の日付は、PDFを出した操作の日になります。ご入金いただいた日を印字すべきでしょうか。

    Now入金日は登録されていますが、領収書には反映されず、出した日が印字されます。

ご入金と供花について

  1. 分割でのご入金や、一部だけ先にいただくことはありますか。また、供花のご請求は本体のご請求と同じタイミングで出しますか、別に出しますか。

    Now入金は全額を一度にいただく前提で、登録するか取り消すかのどちらかです。供花のご請求は、ご注文主ごとに別の画面から出す仕組みになっています。

お願い
上の9点について、「これで合っている」「ここは実際と違う」を番号でお知らせください。
現場の進め方に合わせて、システム側を調整いたします。
