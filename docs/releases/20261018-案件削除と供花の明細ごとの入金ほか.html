案件の削除と削除履歴、供花の入金を1件ごとに

玉泉院 葬儀業務システム 2026年10月18日 7e20b21

管理者が案件を削除できるようにし、削除した案件は削除履歴に残すようにしました。 供花の入金は、請求先ごとのまとめて入金から、供花1件ごとの入金に変えています。 あわせて、商品マスタ・プラン設定の変更履歴、社員ロール「経理」の追加、見積・請求書の金額まわりの修正を反映しました。

案件の削除と削除履歴

案件一覧 / 「削除履歴」画面（管理者のみ）

案件一覧の各行の右端に「削除」ボタンを追加しました。管理者でログインしたときだけ表示されます。 押すと、一緒に消える見積・請求書・入金・供花の件数を確認で表示し、了承すると案件ごとまとめて削除します。

確認の表示例
受付番号1100 山田　太郎 の案件を削除します。
見積2件・請求書1件・入金1件・供花3件も一緒に削除されます。
※入金データがあります。
削除したデータは削除履歴に保存されます。よろしいですか？
  • 削除する前に、案件と関連するデータ一式をそのまま保存してから消します。保存できなかったときは削除も行いません
  • メニューの「削除履歴」（管理者のみ）で、いつ・誰が・どの案件を消したかと、一緒に消えた件数を確認できます。開いた直後は直近30日分を表示し、削除日・受付番号・故人名・喪主名で絞り込めます
  • 画面からの復旧はできません。誤って消した場合はご連絡ください。保存してあるデータから戻します

供花の入金を1件ごとに

供花画面 / 供花の領収書一括印刷

これまで

入金は請求先ごとに「まとめて入金」していました。同じ請求先の供花のうち、一部だけ入金があった場合を記録できませんでした。

これから

供花の明細1件ごとに「入金完了」「入金取消」を押します。請求先には、中の供花の状況から入金済／一部入金／未入金を表示します。

  • 画面上部に、案件全体の請求額合計・入金額合計・未入金額合計を表示します（絞り込みに関係なく案件全体の額です）
  • 「すべて／入金済み／未入金」で供花の明細を絞り込めます。件数も表示します
  • 画面の金額はすべて税抜に揃えました。税込の金額は請求書・領収書のPDFで出ます
  • 入金済みの供花は、金額や請求先が領収書と食い違わないよう、編集・削除できません。直す場合は先に「入金取消」を押してください
  • 領収書の一括印刷には、入金済みの供花だけが載ります
  • 画面・請求書・領収書・入金記録で、税込額の計算を同じものに揃えました

これまで請求先単位で入金済みにしていたものは、その請求先の供花すべてを入金済みとして、入金日もそのまま引き継いでいます。

商品マスタ・プラン設定の変更履歴

「変更履歴」画面（管理者のみ）

商品・種類・セットの中身・並び順・プラン・プラン別の商品設定・増額の選択肢を登録・変更・削除したときに、 誰が・いつ・何をどう変えたかを記録するようにしました。メニューの「変更履歴」で確認できます。

  • 変わった項目だけを「変更前 → 変更後」で残します。内容を変えずに保存した場合は記録しません
  • 期間・担当者・種類・対象の名前で絞り込めます
  • 記録できなかったときは、変更そのものも保存しません

あわせて直した不具合

商品の編集で、保存が途中でエラーになっても、それまでの変更だけが保存されてしまうことがありました。すべて保存するか、何も保存しないかのどちらかになるよう直しています。

見積・請求書の修正

見積画面 / 請求画面 / 見積書・請求書・領収書PDF

自由項目でマイナスの金額を入力できるように

自由入力の行で、一般価格・会員価格にマイナスの金額を入れられるようにしました。値引きや調整に使えます。 会費入金を差し引いた差引合計がマイナスになる場合も、0で止めずにマイナスのまま出します。

  • 領収書のPDFでも、マイナスの金額は他の書類と同じ「▲」で表示します
  • 商品に付く追加行はこれまでどおり0以上、満期サービスは0以下のままです

直した不具合

  • 重箱のようにグループから選ぶ商品で、数量を2以上にしても保存すると1に戻っていたのを直しました。画面の合計だけが多く見えていました。開き直したときも保存した数量で表示します
  • チェックを外した固定料金の行（会葬礼状の版代など）が、画面の合計にだけ足されていたのを直しました。画面の合計が、保存された金額・PDFより多くなっていました
  • 請求書で施行割増券を入力できなかったのを直しました
  • 金額欄で入力済みの数字を選択したまま「-」から打ち直すと、「-」が消えてプラスで入っていたのを直しました（すべての画面の金額欄に効きます）

見積・請求画面でチェックの付け外しや数量を変えたあと、「画面の合計」「保存された金額」「PDFの合計」が一致するかを自動で確かめる検査を導入しました。今回の修正もこの検査で確認しています。

案件・社員まわり

案件画面 / 社員画面

  • 喪主名を必須から外しました。喪主が決まっていない段階でも、空のまま案件を登録・更新できます
  • 社員のロールに「経理」を追加しました（決裁者の次に並びます）。経理は請求書の確認欄（担当者・事務員・決裁者）を押せません
  • 社員一覧で、非表示にした社員（退職者）を有効な社員の後ろに並べるようにしました

画面表記の日本語化

全画面 / 見積書・請求書PDF

  • 日本語の見出しと重なっていた英字の小見出しを外し、英字だけだった表記を日本語にしました
  • 見積書・請求書PDFの明細の上に出ていた「Selected Items」を外しました
  • 見積番号・請求番号の欄の説明文が、欄の幅で細かく折り返されていたのを1行で読めるようにしました

ご確認いただきたいこと

供花の入金 / 経理担当の社員

供花の入金状況

これまで請求先単位で入金済みにしていた供花は、中の供花すべてを入金済みとして引き継いでいます。 実際には一部しか入金がなかった請求先があれば、該当する供花の「入金取消」を押して未入金に戻してください。

経理担当の方のロール

経理の方を「経理」ロールに切り替える場合は、社員画面で各社員のロールを変更してください。
