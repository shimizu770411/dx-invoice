見積番号の新しい採番ルールと、一般書類の価格表示

玉泉院 葬儀業務システム 2026年10月14日 0ae55a7

見積番号を、ご提示いただいたルールどおり「本見積で、葬儀・告別式の年月から採番」する形に改めました。 請求書は見積番号をそのまま引き継ぎます。 あわせて、一般のお客様向けの書類から会員価格を外し、請求書の振込先と備考欄の表示を整えています。 本番データでは、事前相談見積に付いていた旧ルールの見積番号を一括で消しています（後述）。

見積番号の採番ルール

見積画面 / 本見積の作成 / 請求書の作成

これまで

事前相談見積を作った時点で、受付日の年月で番号が付いていました。本見積には番号が付かず、請求書は請求書だけで別に番号を振っていたため、同じ案件で見積と請求書の番号が食い違っていました。

これから

番号は本見積を作るときに付きます。葬儀・告別式の開始日時の年月（YYYYMM）に、その月の最大の番号＋1を付けます。請求書を作ると、見積番号がそのまま請求番号になります。

書類ごとの番号の付き方
書類番号
事前相談見積付きません。画面の見積番号欄もなくなりました
本見積作成時に自動で付きます（告別式の開始日時が入っている場合）
請求書見積番号をそのまま引き継ぎます
領収書請求番号と同じです

告別式の日時がまだ決まっていないとき

告別式の開始日時が未入力のまま本見積を作ると、番号なしで作成されます。 日時が決まったら案件に入力し、本見積の見積番号欄の横にある「自動採番」ボタンを押してください。 ボタンは見積番号が空のときだけ押せます。

  • 月の判定は日本時間です。月初の早朝の告別式も、その月の番号になります
  • 一度付いた番号は、あとから告別式の日付を別の月に変えても変わりません
  • 本見積の見積番号と請求書の請求番号は、これまでどおり手で入力・修正もできます
  • 見積番号のない本見積からは、請求書を作れません。「見積番号が未入力です…」と表示されたら、見積画面で番号を入力するか「自動採番」を押してから作り直してください

すでに作成済みの請求書の番号はそのままです。過去に請求書だけで振った番号と、新しい見積番号がたまたま同じになった場合は、請求書の作成を止めてお知らせします（次項）。

番号が重複したときのお知らせ

本見積の更新 / 請求書の更新 / 請求書の作成

番号が他の書類と重なって保存・作成できないとき、どの書類と重なっているかを表示するようにしました。一覧の「No」と故人名で探せます。

表示例
見積番号「202610120」は既に他の見積（受付No. 1100・故人 山田　太郎の本見積）で使用されています
請求番号「202607001」は既に他の請求書（受付No. 1050・故人 佐藤　花子）で使用されています
  • ほぼ同時に別の方が同じ月の番号を採番したときは「もう一度押してください」と表示されます。押し直せば次の番号が付きます

一般の書類に会員価格を出さない

見積・請求画面 / 見積書・請求書PDF

これまで

一般のお客様の書類でも、明細表に「一般価格」と「会員価格」の2列が並んで印字されていました。

これから

一般の書類では会員価格の列がなくなり、その分、摘要欄が広くなります。会員の書類は従来どおり2列です。

  • 一般の書類では、会費入金額の行も出ません。解約手数料・値引の金額は一般価格の列に出ます
  • 画面でも、一般の書類では種類選択の「会員: ¥…」の表示と、控室管理費などの会員価格の入力欄を出しません
  • 会員で価格を入力してから一般に切り替えても、会員価格は消えずに残ります。会員に戻すと同じ値で表示されます
  • 領収書はもともと選んだ区分の金額だけを出しているため、変更はありません

請求書の振込先と備考欄

請求画面「各担当、備考欄」タブ / 請求書PDF

振込先の口座名義を2行目に

振込先を1行に詰めていたため、文字がかなり小さく縮んでいました。口座名義を次の行に分け、備考と同じ大きさで印字します。

請求書の備考欄の最下部
お振込先：琉球銀行　本店営業部　普通　1234567
　　　　　カ）ニホンフェニックス

備考の入力は8行まで

請求書の備考は、これまで11行まで入力できましたが、PDFでは振込先と重なって9行目以降が切れていました。 請求書の備考欄と、自社情報の「請求書の備考の初期値」を8行までにしました。見積書は11行のままです。

データ修正

本番データ / 2026年10月14日実施

新しいルールに合わせ、事前相談見積に付いていた旧ルールの見積番号を消しました。本見積・請求書・領収書の番号には触れていません。

  • 修正の直前に、本番データ全体のバックアップを取っています
  • 事前相談見積のPDFでは、右上の「受付No.」欄が空欄になります
  • 旧番号が消えたことで、本見積の番号が事前相談見積の番号と重なって番号が飛ぶことはなくなります

対応をお願いしたいこと

番号のない本見積

これまで本見積には番号が付いていなかったため、番号のない本見積が残っています。 まだ請求書を作っていないものは、そのままでは請求書を作れません。

手順

  • 案件に葬儀・告別式の開始日時が入っているか確認し、なければ入力
  • 本見積を開き、見積番号欄の横の「自動採番」を押す
  • 番号が付いたことを確認してから、請求書を作成

請求書を作成済みの本見積は編集できないため、番号はそのままで問題ありません。
